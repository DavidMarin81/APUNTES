# Conexión con la base de datos
## Configuración de la cadena de conexión en `appsettings.json`
- Abrir `appsettings.json` y añadir una sección `ConnectionStrings`:
    ~~~C#
    {
        "ConnectionStrings": {
            "Default": "Server=localhost;Database=MiBaseDatos;User=miUsuario;Password=miPassword;"
            //"Default": "Database=df_excepciones; Data Source=localhost;port=3309;user=root;password=xxx;"
        },
        "Logging": {
            "LogLevel": {
            "Default": "Information",
            "Microsoft.AspNetCore": "Warning"
            }
        },
        "AllowedHosts": "*"
    }
    ~~~

## Instalar paquetes necesarios
- En la terminal:
    ~~~bash
    dotnet add package MySql.Data
    dotnet add package Dapper
    ~~~
- `MySql.Data` -> driver de MySQL
- `Dapper` -> micro ORM para consultas rápidas

## Registrar la conexión en `Program.cs`
- Esto le dice a ASP.NET: "Cada vez que alguien pida un `IDBConnection`, dale un `MysQLConnection` usndo esta cadena de conexión"
    ~~~C# 
    using MySql.Data.MySqlClient;
    using System.Data;

    builder.Services.AddTransient<IDbConnection>(sp =>
        new MySqlConnection(builder.Configuration.GetConnectionString("Default")));
    ~~~
- `"Default"` es el nombre que le damos a `ConnectionStrings`

## Creamos el `Repository` e inyectamos `IDBConnection`
~~~C# 
using System.Data;
using Dapper;
using WebPortalClientesReact.DTOs;

public class UsuarioRepository
{
    private readonly IDbConnection _dbConnection;

    public UsuarioRepository(IDbConnection dbConnection)
    {
        _dbConnection = dbConnection;
    }

    public async Task<UsuarioDTO> ObtenerUsuarioPorId(int id)
    {
        var sql = "SELECT Id, Nombre, Email FROM usuarios WHERE Id = @Id";
        return await _dbConnection.QueryFirstOrDefaultAsync<UsuarioDTO>(sql, new { Id = id });
    }
}
~~~

## Registramos el `Repository` en `Program.cs`
- Añadimos después de la inyección del IDbConnection
    ~~~C#
    builder.Services.AddScoped<UsuarioRepository>();
    ~~~

## Abrir y cerrar la conexión correctamente
- Con Dapper, lo recomendable es abrir la conexión justo antes de usarla y cerrarla después
    ~~~C#
    public async Task<int> IncrementarFallos(int idUsuario)
    {
        using var conn = _dbConnection;
        await conn.OpenAsync();
        var sql = "UPDATE usuarios SET Fallos = Fallos + 1 WHERE Id = @Id";
        return await conn.ExecuteAsync(sql, new { Id = idUsuario });
    }
    ~~~

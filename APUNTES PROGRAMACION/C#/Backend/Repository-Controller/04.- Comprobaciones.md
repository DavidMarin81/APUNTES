# Comprobaciones de datos en el `Controller`
## Comprobaciones de `números`
- `id > 0` -> para asegurarnos de que un identificador sea válido
    ~~~C#
    if (id <= 0) return BadRequest("Id inválido");
    ~~~
- `valor >= 0` -> para cantidades, edades, stock, ...
- `valor > min && valor > max` -> para rangos aceptables
    ~~~C#
    if (edad < 0 || edad > 120) return BadRequest("Edad inválida");
    ~~~

## Comprobaciones de `string`
- No nulo ni vacío
    ~~~C#
    if (string.IsNullOrWhiteSpace(nombre)) return BadRequest("Nombre obligatorio");
    ~~~
- Longitud mínima / máxima
    ~~~C# 
    if (nombre.Length > 50) return BadRequest("Nombre demasiado largo");
    ~~~
- Validación de formato (correo, teléfono, regex)
    ~~~C#
    if (!Regex.IsMatch(email, @"^[^@\s]+@[^@\s]+\.[^@\s]+$"))
        return BadRequest("Email inválido");
    ~~~

## Comprobaciones de `nullables` / `objetos`
- No nulo
    ~~~C# 
    if (obj == null) return BadRequest("Objeto requerido");
    ~~~
- Propiedades de objetos no nulas
    ~~~C#
    if (persona?.Nombre == null) return BadRequest("Nombre es obligatorio");
    ~~~

## Comprobaciones de `listas` o `colecciones`
- Que contenga elementos
    ~~~C#
    if (items == null || !items.Any()) return BadRequest("No hay elementos");
    ~~~
- Que no exceda un límite
    ~~~C#
    if (items.Count > 100) return BadRequest("Demasiados elementos");
    ~~~

## Comprobaciones de `fechas`
- Que no sea futura/pasada
    ~~~C# 
    if (fecha > DateTime.Now) return BadRequest("Fecha no puede ser futura");
    ~~~
- Que esté dentro de un rango
    ~~~C#
    if (fecha < fechaInicio || fecha > fechaFin) return BadRequest("Fecha fuera de rango");
    ~~~

## Comprobaciones de `booleanos`
- Normalmente no requieren validación si vienen del frontend, pero a veces puedes forzar que sea `true` o `false` según reglas
    ~~~C# 
    if (!activo) return BadRequest("Debe estar activo");
    ~~~

## Comprobaciones combinadas o de negocio
- Que un valor dependa de otro
    ~~~C#
    if (fechaFin < fechaInicio) return BadRequest("Fecha fin debe ser mayor que fecha inicio");
    ~~~
- Que una relación exista en la DB
    ~~~C#
    if (!_repositorio.ExisteUsuario(idUsuario)) return BadRequest("Usuario no existe");
    ~~~

## Comprobaciones en los `DTOS` y en los `Controllers`
- Para `controllers` con `[ApiController]` puedes usar **data annotations** en los DTOs y aprovechar la validación automática con `ModelState.IsValid`
    ~~~C#
    public class PersonaDTO
    {
        [Required]
        [StringLength(50)]
        public string Nombre { get; set; }

        [Range(0, 120)]
        public int Edad { get; set; }
    }
    ~~~
- Luego en el `controller`
    ~~~C#
    if (!ModelState.IsValid) return BadRequest(ModelState);
    ~~~

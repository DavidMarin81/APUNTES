# Respuestas HHTP más comunes en Apis .NET
## 200 - OK
- Petición correcta, devuelve datos
    ~~~C#
    return Ok(persona);
    ~~~

## 400 - Bad Request
- El cliente envió datos incorrectos o incompletos
    ~~~C#
    return BadRequest("Datos inválidos");
    ~~~
- También puedes devolver `ModelState`
    ~~~C#
    return BadRequest(ModelState);
    ~~~

## 401 - Unauthorized
- El usuario no está autenticado
    ~~~C# 
    return Unauthorized("No estás autenticado");
    ~~~

## 403 - Forbidden
- El usuario está autenticado pero NO tiene permisos
    ~~~C#
    return Forbid("No tienes permisos");
    ~~~

## 404 - Not Found
- El recurso no existe
    ~~~C#
    return NotFound("Usuario no encontrado");
    ~~~

## 409 - Conflict
- Confictos de unidad, datos duplicados, ...
    ~~~C#
    return Conflict("El usuario ya existe");
    ~~~

## 500 - Internal Server Error
- Error inesperado en el servidor
    ~~~C#
    return StatusCode(500, "Error interno del servidor");
    ~~~

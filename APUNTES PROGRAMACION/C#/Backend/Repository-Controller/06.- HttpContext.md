# HTTPContexto
## Resumen
- Guardar en sesión
    ~~~C#
    HttpContext.Session.SetString("Clave", "Valor");
    ~~~
- Leer de sesión
    ~~~C#
    var valor = HttpContext.Session.GetString("Clave");
    ~~~
- Guardar objetos
    ~~~C#
    HttpContext.Session.SetString("Usuario", JsonConvert.SerializeObject(usuario));
    ~~~
- Recuperar objetos
    ~~~C#
    var usuario = JsonConvert.DeserializeObject<UsuarioDTO>(
        HttpContext.Session.GetString("Usuario")
    );
    ~~~
- Borrar
    ~~~C#
    HttpContext.Session.Remove("Clave");
    HttpContext.Session.Clear();
    ~~~

## ¿Qué es `HttpContext`?
- `HttpContext` es un objeto que ASP.NET Core crea pra cada petición HTTP
- Contiene toda la información sobre la petición actual, como:
    - El usuario autenticado
    - Las cookies
    - La sesión
    - Las cabeceras
    - La IP del cliente
    - Los claims
    - El request y response
    - Los datos del routing
    - ...
- Lo usas siempre que necesitas acceder a datos del usuario o del request

## ¿Dónde se usa?
- Puedes usarlo
    - Dentro de un `Controller`
        ~~~C#
        public class UsuariosController : ControllerBase
        {
            [HttpGet("ip")]
            public string GetIp()
            {
                return HttpContext.Connection.RemoteIpAddress.ToString();
            }
        }
        ~~~

## Habilitar la Session en `Program.cs`
~~~C#
builder.Services.AddSession(options =>
{
    options.IdleTimeout = TimeSpan.FromMinutes(30);
});
builder.Services.AddHttpContextAccessor();

var app = builder.Build();
app.UseSession();
~~~

## Guardar datos en sesión
- Puedes guardar
    - strings
    - números convertidos a string
    - objetos serializados en JSON
- Ejemplo. Guardar un usuario tras login
    ~~~C#
    var jsonUsuario = JsonConvert.SerializeObject(usuario);
    HttpContext.Session.SetString("Usuario", jsonUsuario);
    ~~~
- Ejemplo. Guardar valores simples
    ~~~C#
    HttpContext.Session.SetString("Nombre", "David");
    HttpContext.Session.SetInt32("Edad", 25);
    ~~~

## Obtener datos de sesión
~~~C#
var nombre = HttpContext.Session.GetString("Nombre");
var edad = HttpContext.Session.GetInt32("Edad");
~~~

- Obtener un objeto usuario
    ~~~C#
    var json = HttpContext.Session.GetString("Usuario");

    if (!string.IsNullOrEmpty(json))
    {
        var usuario = JsonConvert.DeserializeObject<UsuarioDTO>(json);
    }
    ~~~

## Eliminar un valor
~~~C#
HttpContext.Session.Remove("Usuario");
~~~
- Eliminar toda la sesión
~~~C#
HttpContext.Session.Clear();
~~~

## ¿Dónde más sirve `HttpContext`?
- Obtener cabeceras
    ~~~C#
    var userAgent = HttpContext.Request.Headers["User-Agent"];
    ~~~
- Obtener claims del usuario autenticado
    ~~~C#
    var email = HttpContext.User.FindFirst("email")?.Value;
    ~~~
- Obtener la IP
    ~~~C#
    var ip = HttpContext.Connection.RemoteIpAddress.ToString();
    ~~~
- Acceder a cookies
    ~~~C#
    var cookie = HttpContext.Request.Cookies["MiCookie"];
    ~~~
